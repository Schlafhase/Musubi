Try Musubi

Musubi is a functional programming language designed to be as close to the Lambda Calculus as possible while still being usable. Resources about Musubi can be found on the GitHub repository.

This little website allows you to try Musubi without installing it. To make it actually useful, the server also has the standard library installed. Include it using #include stdlib.

If you want to do some actual development in Musubi, please install the compiler locally and use a code editor. I made a treesitter parser for syntax highlighting and an LSP server which really help you write Musubi code.
